# 🎥 Said Background Recorder

A simple and flexible Android video recording application.

## ✨ Features
- 🎬 Background video recording (where supported)
- 🔒 Screen-off recording (subject to device and Android restrictions)
- 📱 Simple and user-friendly interface
- 💾 Save recorded videos on your device
